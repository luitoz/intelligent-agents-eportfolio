Welcome to Week 5. This week’s lecturecast focuses on the way in which agents communicate with each other. The lecturecast also looks at the theory of language with Speech Acts and then provides an example of an agent communication language (KQML). Finally, an introduction to ontologies and the way they can be used in agent communications will be discussed. 

## Learning outcomes
- Develop the ability to develop and work with ontologies.
- Create inter-agent communications using relevant languages.
